## 1. 模块式光开关

### 1.1 硬件连接

#### 接口说明
- **电源接口 (J4)**: 
  - Pins 1, 2: Ground
  - Pins 3, 4: +12 VDC
  - 线缆型号: A-1000-10068-A

- **通信接口 (J1)**:
  - Pin 1: RXD
  - Pin 2: TXD  
  - Pin 3: Ground
  - 线缆型号: A-1000-10071-B

#### 连接步骤
1. 将电源线缆连接到J4接口
2. 将串口线缆连接到J1接口
3. J1与电脑串口连接
4. 硬件搭建完成

### 1.2 超级终端设置

#### 推荐软件
- 使用超级终端 **Teraterm**

#### 设置步骤
1. 启动Teraterm后选择serial port
2. Port选择对应的COM口
3. Setup下拉菜单选择Serial Port
4. 其他设置保持默认配置

### 1.3 常见使用命令

#### 初始化
- 上电预热1分钟，完成初始化
- 输入`*idn?`返回"SCPI READY"表示可以开始配置

#### SCPI常用命令

| 命令 | 说明 | 示例及返回值 |
|------|------|-------------|
| `*idn?` | SCPI信息查询 | `*idn?`<br>返回: `POLATIS,S-OSM-48X48-MA1-DSBE V-042,00001542,5.2.0.11` |
| `:oxc:swit:size?` | 查询输入、输出端口数量 | `:oxc:swit:size?`<br>返回: `16,16` |
| `:oxc:swit:disc:all` | 断开所有链接 | `:oxc:swit:disc:all`<br>返回: `<none>` |
| `:oxc:swit:port:stat? (@1)` | 查询端口状态 | `:oxc:swit:port:stat? (@2,4,6)`<br>返回: `(D,E,F)` |
| `:oxc:swit:conn:add (@1),(@17)` | 创建端口连接 | `:oxc:swit:conn:add (@1),(@17)`<br>返回: `<none>` |
| `:oxc:swit:conn:add (@1,2,3),(@17,18,19)` | 同时创建多个端口连接 | `:oxc:swit:conn:add (@1,2,3),(@17,18,19)`<br>返回: `<none>` |
| `:oxc:swit:conn:sub (@1),(@17)` | 断开端口连接 | `:oxc:swit:conn:sub (@1),(@17)`<br>返回: `<none>` |
| `:oxc:swit:conn:port? 1` | 查询指定端口对应的连接端口 | `:oxc:swit:conn:port? 1`<br>返回: `"17"` |
| `:oxc:swit:conn:stat?` | 查询所有连接端口 | `:oxc:swit:conn:stat?`<br>返回: `(@1,2,3),(@17,18,19)` |

**端口状态说明**:
- D: Disabled Channel (禁用通道)
- E: Enabled Channel (启用通道)  
- F: Failed Channel (故障通道)

## 2. 机架式光开关

### 2.1 IP地址更改

#### 电源配置
- 可选220V交流电或48V直流电源供电
- 通过网线连接电脑实现通信

#### 网络接口配置
- **小端口数光开关**: 配置一个网口
- **大端口数光开关(320×320/384×384)**: 配置两个网口

#### 默认IP地址
- **E0接口**: 192.168.0.1
- **E1接口**: 192.168.1.1

#### IP更改步骤
1. 打开"网络和共享中心"
2. 点击对应网络的"本地连接"
3. 双击"属性"
4. 将电脑网段设置成192.168.0.x
5. 在浏览器中输入E0 IP地址
6. 用户和密码均输入"root"
7. 点击"Network Config"
8. 配置IP Address和Broadcast Address为相同网段
9. 勾选Check前的复选框
10. 点击Submit提交
11. 断开光开关电源，等1分钟后上电
12. 更改电脑IP网段后连接

### 2.2 Web页面控制

#### 操作说明
- 左侧端口(1-64)通常作为输入端口
- 右侧端口(65-128)通常作为输出端口
- Polatis光开关是双向的，端口既可用作输入也可用作输出
- 点击两个端口即可创建连接
- 再次点击相同端口可断开连接

#### 应用场景
- 测量通道插损(IL)
- 测试插损重复性(Loss Repeatability)

### 2.3 TL1命令

#### 前置设置
在"控制面板"→"程序"→"打开或关闭Windows功能"中勾选Telnet相关功能

#### 连接方式
```bash
telnet IP 3082
```
- IP: 光开关设备IP地址
- 3082: TL1协议服务端口号

#### 登录说明
- 使用超级账户登录后默认不回显命令
- 输入分号后回车，之后输入命令可回显
- 一段时间未操作会自动退出，需重新登录

#### TL1常用命令

| 命令 | 说明 |
|------|------|
| `act-user::root:123::root;` | 超级账户登录命令 |
| `ent-patch::1,385:123:;` | 创建端口1和385的连接(384×384为例) |
| `ent-patch::1&7&9,385&391&400:123:;` | 同时创建多个端口连接 |
| `dlt-patch::1:123:;` | 断开与端口1关联的光路连接 |
| `dlt-patch::1&8:123:;` | 断开与端口1、端口8关联的光路连接 |
| `dlt-patch::1&&8:123:;` | 断开与端口1～端口8关联的光路连接 |
| `dlt-patch::all:123:;` | 断开所有光路连接 |
| `rtrv-patch:::123:;` | 查询所有连接端口 |
| `rtrv-patch::1&5:123:;` | 查询与端口1、端口5关联的光路连接 |
| `rtrv-patch::1&&768:123:;` | 查询与端口1～端口768关联的光路连接(384×384为例) |
| `init-sys::system:123::0;` | 清除所有光路连接，使能所有端口，关闭衰减，重置功率监测配置和告警，清除保护开关链路配置 |
| `init-sys::system:123::10;` | 重启光开关 |
| `rtrv-eqpt::boot:123:::parameter=mode;` | 查询光开关start-up工作模式 |
| `ed-eqpt::boot:123:::mode=auto;` | 异常断电/重启后自动恢复断电或重启前的所有光路连接 |
| `ed-eqpt::boot:123:::mode=dark;` | 异常断电/重启后清除断电或重启前的所有光路连接 |
| `rtrv-alm-eqpt::all:123:;` | 查询所有光开关设备告警 |
| `rtrv-alm-env::all:123:;` | 查询所有光开关工作环境告警 |

## 重要注意事项

1. **命令格式**: 请注意命令中的空格，严格按照文档格式输入
2. **端口编号**: 不同型号光开关的端口编号范围不同，请根据实际设备调整
3. **网络配置**: 更改IP地址后需要重启设备才能生效
4. **安全操作**: 使用管理员权限运行命令提示符
5. **连接稳定性**: 长时间未操作会自动退出，需要重新登录
