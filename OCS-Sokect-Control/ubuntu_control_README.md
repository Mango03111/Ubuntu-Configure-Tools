# Ubuntu光开关控制脚本使用说明

## 概述

这是一个专为Ubuntu系统设计的光开关控制脚本，基于原有的`simple_optical_switch.cpp`重新实现。脚本使用Bash编写，通过TCP连接控制Polatis光开关设备，支持SCPI命令协议。

## 系统要求

- Ubuntu 18.04+ (或其他Linux发行版)
- Bash 4.0+
- netcat (nc命令)

## 安装依赖

```bash
sudo apt-get update
sudo apt-get install netcat-openbsd
```

## 使用方法

### 1. 设置脚本权限

```bash
chmod +x ubuntu_optical_control.sh
```

### 2. 运行脚本

```bash
./ubuntu_optical_control.sh
```

### 3. 输入光开关IP地址

脚本启动后会要求输入光开关的IP地址，格式为：xxx.xxx.xxx.xxx

### 4. 主要功能

脚本提供以下功能：

1. **查询设备信息** - 获取设备ID和状态
2. **查询光开关端口规模** - 显示端口数量信息
3. **建立光路连接** - 使用格式 `输入端口,输出端口`（如：1,17）
4. **断开光路连接** - 使用格式 `输入端口,输出端口`（如：1,17）
5. **批量建立连接** - 同时建立多个端口连接
6. **批量断开连接** - 同时断开多个端口连接
7. **查询所有连接** - 显示当前所有连接状态
8. **断开所有连接** - 一次性断开所有连接
9. **自定义SCPI命令** - 发送自定义SCPI命令
10. **测试连接功能** - 自动测试连接建立和断开
11. **重新连接设备** - 重新连接到光开关

## 操作格式说明

### 单个连接操作格式

单个连接/断开格式：`输入端口,输出端口`

示例：`1,17` (连接输入端口1到输出端口17)

### 批量操作格式

批量连接/断开格式：`input1,output1;input2,output2;...`

示例：`1,17;2,18;3,19`

## 特性

- **统一输入格式** - 单个和批量操作都使用逗号分隔的端口格式
- **颜色输出** - 不同类型消息用颜色区分
- **输入验证** - 严格验证IP地址和端口号格式(1-32范围)
- **错误处理** - 完善的错误处理和日志记录
- **优雅退出** - 支持q键快速返回菜单
- **连接管理** - 自动处理TCP连接建立和清理
- **优化超时** - 快速响应，控制命令0.1秒超时，查询命令2秒超时
- **连接验证** - 可选的连接状态验证功能
- **SCPI协议** - 完全符合Polatis官方SCPI命令格式

## 安全注意事项

- 确保网络连接安全
- 仅在授权的网络环境中使用
- 定期检查设备连接状态
- 避免在生产环境中进行未经测试的批量操作

## 故障排除

### 连接失败
1. 检查IP地址是否正确
2. 确认设备电源和网络连接
3. 验证防火墙设置
4. 检查端口5025是否开放

### 命令无响应
1. 检查SCPI命令格式
2. 确认设备支持该命令
3. 尝试重新连接设备
4. 检查网络延迟和稳定性

### 线程结束符问题
如果遇到 "bad interpreter" 错误：
```bash
dos2unix ubuntu_optical_control.sh
```

### 脚本权限问题
```bash
chmod +x ubuntu_optical_control.sh
```

## SCPI命令格式

脚本使用标准的Polatis SCPI命令格式：

- **设备查询**: `*IDN?`, `*STB?`
- **端口规模查询**: `:oxc:swit:size?`
- **建立连接**: `:oxc:swit:conn:add (@输入端口),(@输出端口)`
- **断开连接**: `:oxc:swit:conn:sub (@输入端口),(@输出端口)`
- **查询连接**: `:oxc:swit:conn:stat?`
- **断开所有**: `:oxc:swit:disc:all`
- **连接验证**: `:oxc:swit:conn:port? 端口号`
